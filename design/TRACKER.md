# MEGA DASH — DEV TRACKER

The single source of truth for design. Edit it in the tracker web app or
directly here — they are the same file.

## How status markers work

Every field carries one marker. **Claude implements `[ready]` fields only.**

| marker | meaning |
|---|---|
| `[ready]` | Owner has asserted this is ready to implement. |
| `[wip]` | Being written. Do not implement. Editing any field sets this automatically. |
| `[draft]` | Generated by Claude as a starting point. Never implement. Rewrite or accept it first. |
| `[todo]` | Empty, nothing written yet. |
| `[na]` | Deliberately not applicable to this boss. |

Editing a field in the web app flips it to `[wip]`. Marking it `[ready]` is a
deliberate act — that is the assertion that it may be built.
