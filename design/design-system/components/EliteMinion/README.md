# EliteMinion

An elite is its base minion with `outline` swapped for `elite-outline` (gold): the same `grid-minion` box, the same frames, one piece of art for both forms.

- **Draw one sheet per minion.** Do not draw an elite version; the gold rim is the only tell, because size stops being one once the difficulty ramp has been running.
- The rim is the outline on the silhouette's outer edge. Dark pixels inside the drawing (eyes, joints) stay as drawn.
- Minions: SPIGLET walks the ground (`spiglet-primary`, `spiglet-secondary`), PIXIE floats (`pixie-primary`, `pixie-secondary`). Each boss has his own copy of each, its most common colour turned into his primary.
- This card shows the rule on the game's own SPIGLET sheet. **In the game today the gold rim reaches only minions still drawn as plain shapes**: a minion with a drawn sheet is shown without it. That is a gap in the game's code, reported to the owner on 5 Nov 2026, not a change to the rule.
