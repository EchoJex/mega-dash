# EliteMinion

An elite is its base minion with `outline` swapped for `elite-outline` (gold): the same `grid-minion` box, the same frames, one piece of art for both forms.

- **Draw one sheet per minion.** Do not draw an elite version; the gold rim is the only tell, because size stops being one once the difficulty ramp has been running.
- The rim is the outline on the silhouette's outer edge. Dark pixels inside the drawing (eyes, joints) stay as drawn.
- Minions: SPIGLET walks the ground (`spiglet-primary`, `spiglet-secondary`), PIXIE floats (`pixie-primary`, `pixie-secondary`), GUNNER flies and stops (`gunner-primary`, `gunner-secondary`). Each boss has his own copy of each.
- This card shows the rule on the game's own SPIGLET sheet. On a drawn minion the game makes the rim itself: four gold copies of the same picture, one pixel out each way, behind it, so the rim follows the drawing frame by frame.
